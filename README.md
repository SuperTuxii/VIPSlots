# VIPSlots

A minecraft mod for adding VIP slots to a minecraft server that allows players to join even when the server is full.

## Usage

- `/vipslots add <player>` (Make a player a VIP. The player will be able to join even if the server is full)
- `/vipslots remove <player>` (Remove a player as a VIP. The player will no longer be able to join when the server is full)
